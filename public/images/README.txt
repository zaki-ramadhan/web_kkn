# Panduan Penempatan Aset Lokal (Folder public/images/)

Folder ini digunakan untuk menaruh file gambar/foto lokal agar langsung bisa dipanggil di website tanpa perlu import:

1. `public/images/team/`
   -> Taruh 20 foto mahasiswa KKN di sini (contoh nama: `safira.jpg`, `fikri.jpg`, dst. atau `1.jpg` s.d `20.jpg`).
   -> Cara panggil di kode: `/images/team/safira.jpg`

2. `public/images/services/`
   -> Taruh gambar layanan kesehatan/Puskesmas/posko di sini (contoh: `posko.jpg`, `poli.jpg`, `jkn.jpg`).
   -> Cara panggil di kode: `/images/services/posko.jpg`

3. `public/images/logo/`
   -> Taruh file logo kampus UIMA, logo KKN, atau logo BPJS di sini (contoh: `logo_uima.png`, `logo_kkn.png`).
   -> Cara panggil di kode: `/images/logo/logo_uima.png`
